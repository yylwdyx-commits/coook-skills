# 上线前检查单（逐条过，全绿再发）

1. **分享卡片**：`<title>`、`<meta name="description">`、`og:title` / `og:description` / `og:image`（绝对地址，≥1200×630）、favicon 都有。发到聊天软件里的卡片长相，最好真转发一次看。
2. **对外文案不露内部**：搜一遍页面和接口报错里有没有内部系统名、服务器名、供应商名、模型名、调试字样、测试数据；有就换成用户能懂的说法。
3. **错误不透传**：接口出错时，用户只看到「出了什么事 + 下一步怎么办」，原始报错进服务端日志，不进页面。
4. **规则覆盖所有入口**：新加的页面/入口，原来的限制（登录、频控、权限、计费）在这里同样生效吗？最好把规则收在最终那一个关口，而不是每个入口各写一份。
5. **手机上能用**：390px 宽度不横滚、按钮够大、表单能输入、键盘弹起不挡输入框。
6. **大文件不走小水管**：图片、视频、安装包放对象存储或 CDN，别从带宽很小的服务器直出。
7. **缓存**：HTML 不缓存或短缓存，带内容指纹的静态资源长缓存；改了样式却看到旧样式，多半是缓存。
8. **上线后真验一遍**：用一个干净的浏览器（无痕/新设备）打开线上地址，走一遍主路径并截图；看到真实效果才说「好了」。

内部工具（只有自己人看）至少过第 2、3 条。
