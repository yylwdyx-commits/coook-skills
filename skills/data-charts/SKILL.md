# 数据做成图表和看板

## 先算对，再画好
1. **先读数据，报一句数据概况**：多少行、哪些列、时间范围、有没有空值和异常值。
2. **关键数字用代码算**（Python/JS），不心算；总数、分组合计、占比都算两遍对照。
3. **异常先处理再分析**：重复行、测试数据、明显错录（负数金额、未来日期）先列出来，说明怎么处理的。
4. 结论先行：回复第一句给判断（「华东贡献了四成，下半年在掉」），再给支撑数字。

## 选图
- 随时间变化 → 折线；分类比较 → 横向柱状（类别名长时）；构成 → 堆叠柱，少用饼图；两个变量的关系 → 散点。
- 一张图只讲一件事；颜色一个意思一个色，强调色只给要说的那一项。
- 数轴从 0 开始（柱状图必须），单位写清楚，数字带千分位。

## 做成可交互的看板
- 单个 html 文件，不用外部库：图表用 SVG 或 canvas 自己画，筛选用原生 select / 按钮。
- 筛选后，图表和顶部总数一起变；默认状态显示全量。
- 用真浏览器打开、点一次筛选、看截图，确认数字和代码算的一致。
