# 整理文件

## 铁律
- **不删除任何文件**，只移动。重复的、不确定的，移到一个专门的文件夹（如「重复文件」「待确认」），让用户自己决定删不删。
- **原文件不改动**：转格式、缩尺寸时输出到新文件夹，原图一张不动。
- **先出计划再动手**：文件多（几百个以上）时，先跑一遍只读统计，列出「会怎么分」，再执行。
- 动完列清单：每类几个、哪些被移动了、重复的有几组。

## 做法
- **按类型分**：看扩展名（统一转小写），常见映射：图片 png/jpg/jpeg/heic/webp/gif/svg；文档 pdf/doc/docx/ppt/pptx/txt/md；表格 xls/xlsx/csv/numbers；压缩包 zip/rar/7z/tar/gz；安装包 dmg/pkg/exe/msi/apk；其余进「其他」。
- **找重复看内容不看名字**：先按文件大小分组，同大小的再算 SHA-256；名字里的「副本」「(1)」只是线索。每组保留最早的那个（或名字最干净的），其余移走。
- **批量转图**：用 Pillow（或 `sips` / ImageMagick），长边限制时只缩不放，保持比例；按 EXIF 方向先转正；有透明通道转 JPG 时铺白底。
- **按日期整理照片**：优先读 EXIF 拍摄时间，没有再用文件修改时间，并在清单里注明。
- 文件名有中文、空格、括号时，脚本里一律加引号或用 Python 处理，别用 shell 拼字符串。

## 交付
一段话 + 清单：处理了几个、每类几个、重复几组、放在哪里；最后一句说明「没有删除任何文件」。
