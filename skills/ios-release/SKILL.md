# iOS 上架 App Store

判断先行：上架卡住的地方很少是代码，多是**网页上几个只能人点的表单**、**材料和包对不上**、以及**把「请求返回 200」当成「办成了」**。每一步都以苹果后台的真实状态为准。

## 何时用
- 第一次上架一个 App，或发新版本、提审、处理被拒。
- 上传后看不到构建、TestFlight 加不了人、提审报状态错误。

## 判据（怎样算成功）
- 上传成功 = App Store Connect 里该构建状态 VALID（API `/v1/builds` 或网页），不是本地上传工具的日志。
- 提审成功 = 回读版本状态是 `WAITING_FOR_REVIEW`，不是提交接口返回 200。
- 上架成功 = `https://itunes.apple.com/<地区>/lookup?id=<AppID>` 返回 `resultCount:1` 且版本号对，免登录、几分钟内反映。
- **真机**装 TestFlight 包把主路径点一遍。模拟器和网页看不到的崩溃（权限、相册、推送、WebView 行为）只在真机暴露。

## 流程骨架
建 App 记录 → 填元数据（名称、副标题、描述、关键词、类目、隐私政策、版权）→ 价格与销售范围 → App 隐私问卷 → 年龄分级 →（中国区）填备案号 → 出包上传 → TestFlight 内测 → 截图 → 审核信息（演示账号、备注）→ 提审 → 回读状态。

## 坑与真因
**账号与记录**
- App Store Connect API 不能新建 App 记录（`POST /v1/apps` 恒 403），只能网页建。上传报「Cannot determine the Apple ID from Bundle ID」= 记录没建，不是签名问题。
- API 密钥（Issuer ID、Key ID、.p8 私钥）只放私密目录，脚本读路径，绝不进仓库。用 ES256 自签 JWT 即可，不必装重 SDK。
- 内部测试员必须先是账户成员（先发邀请，对方接受后再加进内部组）；外部测试组要过 Beta 审核。内部组设「可访问全部构建」后新构建自动进组。
- Info.plist 写 `ITSAppUsesNonExemptEncryption=false`（不涉及加密出口时），每个构建不用再手答出口合规。

**出包与上传**
- 新装的 Xcode 先 `sudo xcodebuild -runFirstLaunch`；只出真机包也要装 iOS 模拟器运行时（资源编译要用），否则报找不到 simulator runtime。
- 图标不能带 alpha 通道，`sips` 去不掉，要重绘成无 alpha。
- 上传工具首次运行要自建 `~/.itmstransporter`，建不出来时报的是「没权限」，先 `mkdir -p`。
- 上传日志里一堆 TLS 报错不等于失败：那常是可选的前置调用，二进制走另一条路。判断只看后台构建状态。
- 网络对苹果上传域名不稳时，给编译机走一条稳定出口；有的上传工具只认系统级代理、不认环境变量代理。别裸重试十几分钟。
- 上传后苹果处理 5～15 分钟构建才出现。
- 长编译别挂在一条 ssh 上，`nohup` 后台跑再读日志。

**元数据与审核材料**
- **网页三堵墙**：价格与销售范围、App 隐私问卷，公开 API 基本读写不了，必须网页点；提审报 `ENTITY_STATE_INVALID` 时看报错里关联的是哪个资源，别盯着「版本状态不对」猜。
- 年龄分级要一次性 PATCH 全部字段（分次会报缺必填）；新版本问卷会新增必填项，老文档没有。
- 首个版本不能填「新功能（whatsNew）」，之后的版本反而必填。
- 提审失败会留下空的提审草稿，重跑时复用它（挂版本 → 标记 submitted），别新建。
- 隐私问卷、隐私政策、权限描述、实际采集四者必须一致。
- **App 内必须能注销账号**（审核指南 5.1.1(v)），新 App 第一天就设计好。
- 权限只申请用到的：只声明「添加到相册」就只能加图，去建/查相簿属于读整个相册库，会直接闪退；改权限要同步改隐私政策和审核备注的承诺。
- 截图要真机真账号，审核员会读截图里的字：不能出现引导去商店外安装、外部支付之类的话；截图里的手机号等个人信息先打码。6.9 寸位尺寸 1320x2868，相近机型截图等比缩放即可。
- 截图上传是三步：预留 → 分片 PUT → 标记已上传并带 MD5，少最后一步不认。
- 演示账号先用真接口验：首次登录要短信或滑块的号 = 审核员登不进 = 必拒。
- 名称、副标题不要出现赚钱、兼职这类引人联想的词；类目选对，不要报需要额外资质的类目；审核备注写清商业模式。
- 隐私政策链接每次真浏览器打开看是否渲染出条款（单页应用的哈希路由常把人带回首页）。
- **审过的包里没有的功能，只能随新版本送审放出**；用服务端开关在线上放出未审功能违反审核指南 2.3.1，可能连累在架版本和整个开发者账号。

**中国区备案**
- 中国大陆上架需要 App 备案号（在云服务商控制台给 App 单独备案，网站备案号不能直接用）；要法人本人手机验证码和视频核身，提前约人；管局审核最长约 20 个工作日；拿到后 30 天内办公安联网备案。
- iOS 备案填 Bundle ID + 分发证书公钥 + SHA-1 指纹（`openssl x509 -noout -fingerprint -sha1`）。
- 苹果拿备案号去查主办单位，中文主体名与账户英文名对不上会报「提供商名称不符」，页面有确认声明路径，由账户负责人本人勾选。

## 检查清单（提审前逐条）
1. App 记录已建；Bundle ID、版本号、构建号一致；构建 VALID。
2. 价格与销售范围、隐私问卷、年龄分级已在网页完成。
3. （中国区）备案号已填并确认。
4. 能注销账号；权限描述与实际调用一致。
5. 截图真机真账号、已打码、无违规引导；隐私政策页能打开。
6. 演示账号直接可登、进去有真实内容；审核备注写清模式。
7. TestFlight 真机点过主路径，崩溃日志看过。
8. 提审后回读 `WAITING_FOR_REVIEW`；过审后用 lookup 接口确认上架。
