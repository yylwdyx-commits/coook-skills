# 真浏览器验收

## 只认截图
- 用真浏览器（Playwright / Puppeteer 等，有界面无界面都行）打开页面拿截图；读代码、读 DOM、看日志都不算验过。
- 截图要亲眼看：布局有没有塌、文字有没有溢出或被遮、图有没有裂、颜色对不对。

## 像真人一样走
- 从入口进，真点、真输入、真等待；不要直接调接口冒充用户操作。
- 覆盖所有状态：空数据、正常、出错、很长的文本、很多条数据。
- 电脑宽度（1280）和手机宽度（390）各看一次。
- 有动画/游戏时用连续截图或录屏看过程，前后两张截图看不出「中间发生了什么」。

## 判断
- 控制台零报错、没有加载失败的请求，是及格线不是满分。
- 改动的那几行必须真被执行到一次（点到那个按钮、走到那个分支）。
- 发现问题就修，修完再验同一个路径；三次修不好就换思路，并在回复里说清楚还剩什么。

## 回报
「验过了什么路径 + 看到什么 + 还有什么没验到」，附关键截图的文件路径。
