# 整理发票做报销

## 做法
1. **收齐**：把发票 PDF / 图片放进一个文件夹；邮件里的发票先下载附件。
2. **读票**：电子发票 PDF 优先直接抽文字（pdftotext / pdfplumber），抽不出再 OCR；关键字段：发票号码、开票日期、销售方、项目名称、金额、税额、价税合计。
3. **去重**：同一发票号码只算一次；同一张票的 PDF 和图片版本只留一份。
4. **核对**：价税合计 = 金额 + 税额，对不上的标出来；开票日期超出报销期限的标出来。
5. **分类汇总**：交通、住宿、餐饮、办公用品等，每类小计 + 总计，生成 Excel（明细一张表、汇总一张表）。

## 常见坑
- 网约车要同时有「电子发票」和「行程单」，只有一个不完整。
- 同一笔消费拆了多张票，金额加起来再核对。
- 发票抬头和税号必须是报销单位的，抬头不对的单独列出。
- 「提单成功」不等于「报销通过」，回报时说清是哪一步。

## 交付
Excel 路径 + 一句话总计（几张票、多少钱）+ 有问题的票据清单。
