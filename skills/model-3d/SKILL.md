# 画 3D 模型（能直接打印）

## 默认做法
1. **先定尺寸再建模**：把用户说的尺寸写成参数（毫米），没说的按常识补并在回复里说明，比如「手机按 10mm 厚（带壳）留槽」。
2. **用代码生成几何体**，不手搓顶点：
   - 有 Python 时优先 `trimesh` / `numpy-stl` + 布尔运算；没有就用纯 JS/Python 自己拼长方体、圆柱、楔形，再合并。
   - 复杂外形用「拉伸二维轮廓」：先画截面多边形，再沿一个方向拉伸，最不容易出错。
3. **模型必须是封闭实体**（能切片）：每条边恰好被两个三角面共享、法线朝外、没有零厚度面。导出前自己检查一遍，不封闭就修（合并重复顶点、补洞、重新三角化）。
4. **单位是毫米**，模型平放在 Z=0 上，原点放在底面中心附近。
5. **出一张预览图**：渲染成 PNG（matplotlib 的 3D 绘图或离屏渲染都行），让人一眼看出长什么样。

## 设计常识（让打印一次成功）
- 壁厚 ≥ 2mm，卡槽留 0.3~0.5mm 余量；受力处加圆角或加强筋。
- 悬垂角度超过 45° 要支撑；尽量设计成平底直接放，减少支撑。
- 斜靠类（手机支架、平板架）角度 60~70° 最舒服；底座要比重心投影宽，防止前翻。
- 小零件（< 5mm）普通 FDM 打不清，提醒用户。

## 交付
回复写清：外形尺寸（长×宽×高 mm）、建议的摆放方向、要不要支撑、建议层高和填充率。文件：`*.stl`（打印用）+ `preview.png`；用户要上色或做展示再给 `*.glb`。
